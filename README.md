# The Valthakan Times

A client-based capstone project focused on redesigning and rebuilding a personal website for **The Valthakan Times**.

Built with **Next.js** and **TypeScript**, the project integrates the **Beehiiv API** to fetch newsletter content dynamically, allowing the client to continue managing publications through Beehiiv while using a fully independent, custom-built website.

## Features

- 📰 Dynamic newsletter content powered by the Beehiiv API
- ⚡ Independent front-end built with Next.js & TypeScript
- 📱 Fully responsive design across desktop, tablet, and mobile
- ♻️ Reusable React components for scalable development
- 🚀 Deployed on Vercel

## Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- Beehiiv API
- Vercel
